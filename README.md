# Daniel Olorundare | Cybersecurity Portfolio

Static portfolio site (plain HTML and CSS, no build step).

- `index.html` is the page
- `assets/profile.jpg` is the portrait

## Publish with GitHub Pages
1. Push these files to the root of a repository.
2. In the repo, go to Settings > Pages.
3. Under Build and deployment, choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/<repo-name>/`.
   Name the repo `<your-username>.github.io` to get `https://<your-username>.github.io/` instead.
